数据集采集工具 - 使用说明
========================================

一、这是什么
本工具配合迈德威视工业相机，为 YOLO 目标检测训练采集原始图片。
采集时按目标类别自动分文件夹保存，采完可以直接进入打标签环节。

二、安装
1. 使用 64 位 Windows 10 或 Windows 11。
2. 用 USB 线连接迈德威视相机。
3. 请先完整解压整个压缩包，不要直接在压缩包里运行。
4. 双击 install_dataset.bat，弹出管理员授权时选择“是”。
5. 安装脚本会自动安装相机驱动、创建桌面快捷方式并启动程序。

如果目标电脑已经装好迈德威视驱动，也可以直接运行：
DatasetCapture\DatasetCapture.exe

三、先改成实际的目标类别（重要）
1. 用记事本打开：DatasetCapture\config\capture_classes.txt
2. 一行写一个类别名称，改成实际的目标名称，例如：

   红色小球
   黑色颗粒
   小砖块

3. 保存后重新启动程序生效。
   以 # 开头的行是注释，不会算作类别。

类别名称会同时作为文件夹名和图片文件名前缀，建议用简短的中文或英文，
不要包含 \ / : * ? " < > | 这些字符。

四、采集流程
1. 打开程序，等待相机画面出现。
2. 在右侧列表点击要采集的类别。
3. 把目标放到台面上，调整位置和角度。
4. 按空格键，或点击“采集”按钮，保存一张。
5. 换角度、换位置继续采，重复第 3-5 步。
6. 换下一个目标时，点击对应类别，继续采集。

五、快捷键
空格      采集一张
1-9       快速切换到第 1-9 个类别
Ctrl+Z    撤销上一张（删除刚保存的图）
Esc       退出程序

六、建议每个类别采多少张
每个类别建议至少 150-300 张，并且覆盖下面这些变化：
- 不同位置：画面中心、四个角、边缘
- 不同角度：旋转、倾斜、正对、侧对
- 不同光照：开灯、关灯、侧光、阴影
- 不同距离：远近不同的摆放
- 部分遮挡：被其他物体挡住一部分
- 多目标同框：几个目标同时出现在画面里

只要目标在画面中，就尽量多拍；重复角度太多对训练帮助不大。

七、图片保存在哪
DatasetCapture\dataset\<类别名>\<类别名>_0001.jpg
保存的是相机原始分辨率，JPEG 质量 95，没有缩放。

采集完成后，把整个 dataset 文件夹拷贝回来即可。

八、注意事项
1. 不要移动相机位置，也不要改变相机高度，否则尺寸会不一致。
2. 采集过程中保持光照稳定，避免其他人影或手进入画面。
3. 不要删除或移动 _internal、mindvision 目录，程序依赖它们。
4. 每采完一个类别，可以在右侧列表确认采集数量是否正确。

九、常见问题
1. 提示“相机启动失败”或“未发现相机”
   - 关闭可能占用相机的官方相机程序（如 MVDCP2）。
   - 拔插相机 USB 线，确认设备管理器里能看到相机。
   - 再重新打开本程序。

2. 画面全黑或过曝
   用记事本打开 DatasetCapture\config\camera_profile.yaml，
   调整 exposure_us（曝光，微秒）和 gain_x（增益）后重启程序。

3. 预览画面卡顿
   预览帧率不影响保存质量，程序保存的始终是全分辨率原图。

4. 想改相机分辨率或帧速
   修改 camera_profile.yaml 中的 resolution_index 和 frame_speed_index。

十、目录说明
DatasetCapture\DatasetCapture.exe      主程序
DatasetCapture\_internal\              运行库，禁止删除或移动
DatasetCapture\config\                 相机参数和类别列表
DatasetCapture\dataset\                采集的图片，按类别分文件夹
DatasetCapture\mindvision\             迈德威视 64 位运行库
camera_driver\                         相机驱动安装组件
