# 实施计划：婴幼儿小物件 YOLO 风险演示

## 阶段 1：仓库与配置

- 初始化 Git，添加 `origin` 指向用户提供的仓库。
- 创建 Python 包、测试、脚本、配置和数据目录。
- 提供 31 类稳定编号模板与风险规则模板；阈值必须由教师依据选定标准填写。

## 阶段 2：核心逻辑（TDD）

- 先编写风险规则与像素/毫米换算测试并确认失败。
- 实现保守判定：置信度、标定状态、遮挡/边缘、姿态和阈值缓冲区任一不满足即 `无法判断`。
- 实现平面单应性换算和尺寸估计，记录不确定性。

## 阶段 3：工具链

- `capture.py`：从 USB/迈德威视 SDK 可见的 OpenCV 设备采集图片，按类别和场景保存。
- `calibrate.py`：读取棋盘格图片生成相机标定和台面单应性 JSON。
- `check_dataset.py`：检查图片、标签、类别范围和数据集切分。
- `train.py`：调用 Ultralytics YOLO 训练/验证。
- `infer.py`：读取图片/视频/摄像头，检测、测量、判定并输出 JSON/可视化。

## 阶段 4：验证与交付

- 运行单元测试、数据检查帮助命令和脚本语法检查。
- 明确说明未接入真实相机、未采集真实样本、未完成训练权重；这些必须由用户现场完成。
- 给出从采集到比赛演示的操作顺序和标定注意事项。
